# Frontend App (React + Vite)

## Run

```bash
npm ci
npm run dev -- --host 0.0.0.0 --port 5173
```

Open: `http://localhost:5173`

## Scripts

- `npm run dev` — dev server
- `npm run build` — production build
- `npm run preview` — preview build
- `npm run lint` — eslint

## Env

Use `VITE_API_URL` for backend URL.
